2025 Mathematical Contest in Modeling, Problem B: SiC Epitaxial Layer Thickness Data

This repository contains four measured infrared interference spectra supplied with Problem B, *Determination of Silicon Carbide Epitaxial Layer Thickness*, in the 2025 Contemporary Undergraduate Mathematical Contest in Modeling. The data are provided for reference and subsequent modeling work.

## Data Files

| File | Wafer material | Incidence angle | Description |
| --- | --- | ---: | --- |
| `data/附件1.xlsx` | Silicon carbide (SiC) | 10° | Measurement from the same SiC wafer |
| `data/附件2.xlsx` | Silicon carbide (SiC) | 15° | Measurement from the same SiC wafer |
| `data/附件3.xlsx` | Silicon (Si) | 10° | Measurement from the same Si wafer |
| `data/附件4.xlsx` | Silicon (Si) | 15° | Measurement from the same Si wafer |

Each workbook contains 7,469 observations, spanning approximately 399.6747–4000.122 cm⁻¹. The original workbook columns are:

- `波数 (cm-1)`: wavenumber, in cm⁻¹.
- `反射率 (%)`: interference-spectrum reflectance, in percent.

## Source and Reference

The datasets originate from the attachments for Problem B of the 2025 Contemporary Undergraduate Mathematical Contest in Modeling. For related methodological background, see:

> Zhentao Li, Xiang Zhong, Jing Zhong, and Xinge Liu. *High-Throughput full-spectrum characterization of semiconductor thin films via AD-accelerated physics-informed inversion: Demonstrations in Si and SiC epitaxy*. Journal of Alloys and Compounds. DOI: [10.1016/j.jallcom.2026.190602](https://doi.org/10.1016/j.jallcom.2026.190602)

The article PDF is not distributed with this repository. Please obtain the official publication via the DOI and comply with its applicable licensing and copyright terms.

## Notes

The repository preserves the four Excel workbooks without modifying their cell contents. It does not include the article PDF, modeling code, or analysis results.
